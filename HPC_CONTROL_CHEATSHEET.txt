          CHEATSHEET PANDUAN KONTROL & JUPYTER NOTEBOOK HPC NEBULA FMIPA UB
================================================================================

1. PERINTAH DOKUMEN & KONTROL UTAMA HPC
--------------------------------------------------------------------------------
• Login ke HPC:
  ssh hpc-ub

• Masuk ke Folder Proyek AMARUS:
  cd ~/Amarus/AMARUS

• Cek Posisi Direktori Saat Ini:
  pwd

• Lihat Isi Folder (Lengkap):
  ls -la

• Tarik Update Kode Terbaru dari GitHub:
  git pull origin main

• Cek Penggunaan RAM, CPU & GPU HPC:
  htop
  free -h
  nvidia-smi

• Keluar dari SSH HPC:
  exit


2. CARA MASUK KE JUPYTER NOTEBOOK DI HPC
--------------------------------------------------------------------------------
METODE A: Melalui Browser Komputer (Chrome/Edge/Firefox)
1. Buka Terminal BARU di Komputer Lokal (bukan di dalam SSH):
   ssh -L 8888:localhost:8888 hpc-ub

2. Di Terminal HPC yang terbuka, masuk ke folder & jalankan server:
   cd ~/Amarus/AMARUS
   jupyter notebook --no-browser --port=8888

3. Buka Browser Komputer Anda dan paste URL token yang muncul di terminal:
   http://localhost:8888/?token=...


METODE B: Melalui VS Code (Rekomendasi Terbaik)
1. Buka VS Code di Komputer Lokal.
2. Tekan Ctrl+Shift+P -> Remote-SSH: Connect to Host... -> Pilih hpc-ub
3. Open Folder: /home/uid1083/Amarus/AMARUS
4. Klik file: notebooks/JARVIS_DFT3D_Data_Extraction.ipynb


3. MENGIRIM / MENGAMBIL DATA LOKAL <-> HPC
--------------------------------------------------------------------------------
• Mengirim Folder Lokal ke HPC:
  scp -r /home/user/Documents/AMARUS hpc-ub:~/

• Mengirim dengan Rsync (Cepat & Bisa Resume):
  rsync -avz --exclude='.venv' /home/user/Documents/AMARUS hpc-ub:~/

• Mengambil Hasil dari HPC ke Lokal:
  scp -r hpc-ub:~/Amarus/AMARUS/paper_figures /home/user/Documents/AMARUS/


4. EKSEKUSI SIMULASI BACKGROUND (NOHUP)
--------------------------------------------------------------------------------
• Jalankan Notebook di Background tanpa Takut SSH Terputus:
  nohup jupyter nbconvert --to notebook --execute notebooks/JARVIS_DFT3D_Data_Extraction.ipynb --inplace > running.log 2>&1 &

• Cek Proses Background yang Sedang Berjalan:
  ps aux | grep jupyter

• Cek Log Real-Time:
  tail -f running.log
